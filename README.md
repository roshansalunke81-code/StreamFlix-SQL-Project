# StreamFlix SQL Project

## Subscriber Behaviour & Content Performance Analysis

A complete SQL analytics project based on a fictional OTT streaming platform called **StreamFlix**. This project focuses on analyzing subscriber behavior, content performance, engagement trends, and review patterns using advanced SQL concepts such as Joins, Window Functions, Subqueries, CTEs, Aggregations, and Date Functions. 

---

## Project Overview

This project explores a relational database named `Project1`, containing four interconnected tables:

* Users
* Content
* Watch History
* Reviews

The analysis helps uncover:

* User engagement behavior
* Binge watching patterns
* Content popularity
* Subscriber retention
* Rating trends
* Premium user preferences
* Most polarizing content

The project demonstrates how SQL can be used for real-world business analytics in streaming platforms like Netflix, Amazon Prime, or Disney+ Hotstar.
